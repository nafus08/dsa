# Data Structures and Algorithms

A collection of Java solutions for university data-structure labs and algorithm practice problems.

## Tech stack

- Java
- JDK and command-line compiler (`javac`)

## Topics

- Arrays, matrices, sorting, and searching
- Linked lists, doubly linked lists, stacks, queues, and hash tables
- Binary trees, binary search trees, and heaps
- Graph representations, traversal, connectivity, and shortest paths
- Problem-solving exercises covering arrays, trees, graphs, and algorithms

## Repository layout

The numbered `Lab 1` through `Lab 9` folders contain algorithm practice programs. The descriptive `Lab ... [JAVA]` folders contain course lab and assignment tasks, with task-specific README instructions and tester classes where provided.

## Run locally

Install a JDK, clone the repository, and open the Java file for the problem you want to run. Compile and run a standalone class from its folder:

```bash
javac Example.java
java Example
```

Some assignment solutions depend on companion node, helper, or tester classes in the same lab folder. Compile those required files together and follow that folder's README; files from different folders may have duplicate class names.
